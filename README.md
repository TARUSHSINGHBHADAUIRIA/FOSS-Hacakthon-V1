

About
Tulip-AI is an open-source, AI-powered learning planner designed to help users set goals and receive personalized, structured roadmaps to achieve them. Whether you're learning a new skill, preparing for an exam, or building a project — Tulip-AI maps out the journey for you.

✨ Features

🗺️ AI-Generated Roadmaps — Get a personalized step-by-step learning plan for any goal
🎯 Goal-Oriented Planning — Set your target and let Tulip-AI break it down into achievable milestones
⚡ Efficient & Interactive — Clean, responsive web interface for a smooth planning experience
🤖 Powered by Sarvam AI — Uses Sarvam AI's API for intelligent, context-aware responses
